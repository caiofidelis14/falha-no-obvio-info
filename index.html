Falha no Óbvio Studio

Ferramenta interna de produção de vídeos curtos para o canal Falha no Óbvio. O responsável é o único usuário; não é um serviço aberto para outros canais.

Pesquisa fontes oficiais, prepara e revisa roteiros, gera narração e gráficos próprios, verifica qualidade e envia vídeos ao canal autorizado via YouTube Data API.

Canal no YouTube · Política de Privacidade · Condições de uso

Como funciona

A produção ocorre em ambiente privado do GitHub Actions e exige OAuth do titular. Este site apresenta a ferramenta; não oferece login nem executa uploads.

Meta: até três Shorts por dia, de 35 a 60 segundos, conforme fontes, cotas gratuitas e verificações de qualidade. Os uploads são privados enquanto a auditoria da API está pendente.
