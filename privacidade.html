Escopo e dados utilizados

Ferramenta interna de Caio Fidelis para seu próprio canal. Usa identificação do canal autorizado, credenciais OAuth, metadados de vídeos produzidos e IDs/status dos uploads. Não coleta dados dos espectadores e não solicita senhas do Google.

Fontes públicas, roteiros, áudios e vídeos são tratados para produção. Utiliza serviços de API do YouTube, sujeitos também à Política de Privacidade do Google.

Armazenamento e compartilhamento

Credenciais ficam em segredos do GitHub Actions e arquivos locais privados. Metadados ficam em repositório privado. Artefatos diários no GitHub expiram após dois dias; cópias locais ficam até exclusão pelo titular. Registros da fila permanecem para evitar reenvios.

Google/YouTube processam autenticação, geração quando disponível e upload. GitHub executa a produção na nuvem. Voz local de reserva e montagem não dependem de API de voz. Os dados não são vendidos nem usados para publicidade direcionada.

O site público não contém senhas, tokens, chaves ou endereço do responsável. A hospedagem pode processar dados técnicos conforme a política do GitHub.

Revogação e exclusão

O titular pode revogar acesso em Permissões da Conta Google e desativar a rotina no GitHub. Para excluir dados, pode remover arquivos, credenciais e registros dos respectivos serviços e armazenamento. Revogar acesso não exclui automaticamente vídeos enviados ao YouTube.

Não há usuários externos: o responsável também é titular dos dados. Dúvidas gerais sobre esta documentação podem ser enviadas pelas solicitações públicas ao responsável. Não publique credenciais, endereço ou informações confidenciais nesse contato.
